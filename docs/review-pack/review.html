2. 创作模块 · 功能点与具体操作

2.1 创作中心（/create）

功能点用户操作系统行为
六种开始方式点击：从想法 / 搜索结果 / 工作区 / 我的素材 / 商品诊断 / 链接进入对应表单；部分模式要求选工作区或粘贴链接
填写目标输入「我要完成什么」作为项目 goal / brief 上下文
内容类型选择：社媒图文 / 短视频脚本 / 图片 / 文案影响工作台字段与生成提示
目标平台选择：小红书 / TikTok / 抖音 / X / Instagram / LinkedIn影响平台适配与字段标签
创建项目点击创建POST /api/create → 跳转 /create/[id]
历史项目点击列表项进入已有工作台
快捷入口点「AI 图片生产」「我的素材」跳转 /create/image、/assets

2.2 创作工作台（/create/[id]）

功能点用户操作系统行为
改标题编辑标题后失焦PATCH 保存 title
时间线查看目标→上下文→计划→草稿→适配→质检→预览→发布展示创作进度状态
字段编辑编辑标题/Hook/正文/结构/CTA/Hashtags/封面建议本地编辑；保存写入项目
字段 AI 动作优化标题 / 更自然 / 更专业 / 缩短 / 增加信息密度 / 重新生成封面建议按字段改写（可能弹 Credits 确认）
AI 生成草稿点击主按钮调用生成链路，填充统一内容结构
预览切换预览 / 返回编辑按平台样式预览产出
保存点击保存持久化 brief/内容
标记完成点击状态 → completed

2.3 相关周边

  • AI 图片生产 独立 Image Studio：提示词生成/编辑图片任务

3. 跨境商业 · 功能点与具体操作

共性：Demo Store 演示数据；时间范围可切 7 / 30 / 90 天；智能结论面板可带「搜索 / 创作」行动。

3.1 Amazon

页面功能点具体操作
经营概览核心指标、异常商品、行动建议切日期范围；点商品进诊断；跟随建议去搜索/创作
商品诊断列表商品问题排序/列表进入某个 ASIN 详情
商品诊断详情结论 + 证据 + Intelligence Findings查看 CVR/流量等证据；一键带结论去创作
广告诊断花费、ACOS、词/版位问题切范围；下钻异常广告结构
利润销售额、费用、毛利结构看演示利润拆解
库存风险在库/在途、断货风险识别库存风险商品

3.2 TikTok Shop

页面功能点具体操作
经营概览内容→商品→创作者链路指标切范围；跳转内容/商品
商品诊断商品表现与问题进入详情看结论与证据
内容经营视频内容表现列表看视频与商品关联经营数据
Creator / Affiliate达人与分销表现评估合作达人效果

4. 已知薄弱点（供优化讨论）

  • 跨境均为 Demo，缺少真实账号连接与权限边界说明的产品化呈现。
  • 创作工作台信息密度高，时间线 + 多字段 + Credits 确认叠加，窄屏/首次使用成本偏高。
  • 「诊断 → 搜索 → 创作 → 发布」闭环在 UI 上存在入口，但路径文案/引导不够连续。
  • 创作历史项目偏多（含 smoke 测试数据），列表噪音大。
  • 首页与结果页近期改动较多，创作/跨境视觉语言尚未完全统一（卡片密度、导航层级）。
